# Student Task Manager
## About the Project
Student Task Manager is a full-stack web application designed to help students manage their daily academic activities, assignments, and study schedules.
## Features
- Student Registration and Login
- Add New Tasks
- View All Tasks
- Edit Existing Tasks
- Delete Tasks
- Mark Tasks as Completed
- Track Pending and Completed Tasks
## Technologies Used
- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- MySQL
## Project Architecture
The application follows a three-layer architecture:
1. Presentation Layer – HTML, CSS, JavaScript
2. Application Layer – Java and Spring Boot
3. Database Layer – MySQL

See [Student Task Manager Architecture](Student_Task_Manager_Architecture.md) for the complete project architecture, database models, API routes, and frontend screens.
